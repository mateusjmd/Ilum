# Epimodel's - Zombie Apocalypse Edition

Esse subrepositório destina-se ao versionamento dos códigos produzidos para a modelagem populacional de um apocalipse zumbi, a ser utilizado durante as atividades de divulgiação científica no Ilum de Portas Abertas (IPA).

# Referências
MIRANDA FILHO, L. H.; RIBEIRO, B. V.; ROCHA, P. M. M.; SANTOS, D. D. A.; SENA, N. C. de. Surviving the Zombie Apocalypse: A Population Dynamics Based Approach. Revista Brasileira de Ensino de Física, v. 42, e20200071, 2020. DOI: https://doi.org/10.1590/1806-9126-RBEF-2020-0071.
